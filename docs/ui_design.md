# 基本UI詳細設計

実装日：2026-09-30。要件：[README](../README.md#基本uiデザイン2026-09-30実装)

## 共通テーマ

Tailwind CSS v4を継続し、`tailwind.config.ts`の`theme.extend`で既定テーマへトークンを追加する。`globals.css`の`@config`で読み込む。基本色はprimary `#1769aa`、背景 `#f4f8fb`、本文 `#20364b`。白いカード、淡いブルーのsecondary、淡いグリーンのaccentを使用する。色・角丸はCSS変数から参照し、標準のTailwindユーティリティを維持する。日本語はOSの日本語フォントへフォールバックする。

## 共通レイアウト

- ルートレイアウトにSiteHeader／SiteFooterを配置し、短い画面でもフッターを下部へ配置する。本文に既存のmain要素を残し、mainを二重にしない。
- ヘッダー：ホーム、メニュー・Web予約、マイページ、ログイン、会員登録。lg未満ではインラインの開閉メニュー、lg以上では横並び。メニューは通常のリンクとしてTabで操作でき、Escapeで閉じて開閉ボタンにフォーカスを戻す。リンク選択・ページ遷移で閉じる。モーダルではないためフォーカスを閉じ込めない。
- フッター：Web予約、マイページ、店舗スタッフ、管理者。店舗側の認証入口も維持する。
- コンテンツ：スマートフォンは左右16px、smで24px、lgで32px。既存画面のmax-widthを維持し、共通のカード背景・角丸・余白を適用する。
- トップページ：健康とリラクゼーションを表すコピー、予約・会員登録の導線、予約の3ステップ。ヒーローはlgから2列、ステップはmdから3列。架空の施術メニュー・料金・営業時間は表示しない。

## 共通部品と既存画面

shadcn/uiのRadix版ButtonのSlot・CVA構成とCard構成を基に、テーマに合わせたローカルコンポーネントを配置する。`cn`でクラスを結合し、利用側のTailwindクラスを優先できるようにする。`components.json`を用意し、今後のshadcn/ui追加にも同じパス・テーマを使う。

予約・会員手続き・ログインの主要ボタンにButtonを採用する。既存入力欄・選択欄・ボタンには低い優先度のbase layerで共通の色・最小高さ・フォーカスを指定する。画面固有のユーティリティによる上書きを維持する。認証処理・API呼び出し・入力検証・送信中の無効化は維持する。

予約日時は専用の月カレンダーとshadcn/uiのDialogで選択する。空きなしの日の無効化・モーダルの最新検索・選択解除の動作は[Epic 5詳細設計](detailed_design_ep5.md#3-task-512公開空き検索)を参照する。

## アクセシビリティ

本文スキップ、ナビゲーションのラベル、現在ページのaria-current、開閉状態のaria-expanded／aria-controls、装飾アイコンのaria-hidden、可視フォーカス、主要操作領域44px以上を設定する。チェックボックスとラジオの既存ラベル・入力動作は維持する。入力欄の文字サイズは16pxを基本とする。
